# treeti simplicity audit — 10 October 2026

Scope: source-based review of live sign-in, borrower invitations, agreement creation, party approval, witness response, repayment, forgiveness, finalization and settlement. Existing screenshots and synthetic journey checks inform the review; this is not a fresh real hosted multi-person test or a full visual/accessibility audit.

The owner authorized the remaining recommendations on 11 October. All eight changes are now implemented; see [ADR 014](adr/014-simple-verified-session-flows.md) and the [implementation verification](simplicity-implementation.md). The table below retains the original findings for traceability.

Keep: verified identity before private access; readable current terms; a deliberate Agree/Witness/Confirm action; both parties' consent; fresh approval after changed terms; counterparty checks on shared financial records. Private debt entry already follows the simpler signed-in form → save model without action codes.

Target borrower flow: invitation → sign in only if needed → read → agree. Target witness flow: invitation → verify invited email only if needed → read → witness affirmation. Avoid treating an emailed bearer link and a self-entered name as sufficient proof of the invited identity.
